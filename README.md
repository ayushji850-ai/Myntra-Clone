# MODEST. – Myntra Inspired Fashion Store

**MODEST.** is a modern and stylish fashion e-commerce website inspired by Myntra. It provides a premium online shopping experience with a clean user interface, attractive product displays, category-based browsing, and interactive shopping features.

The project is developed using **HTML, CSS, and JavaScript**, focusing on responsive web design and front-end functionality.

## 🌟 Project Overview

MODEST. brings fashion and technology together through a modern shopping interface. Users can explore fashion collections, browse different categories, search for products, filter items, and add products to their shopping bag.

The website features a unique design approach with a premium black, white, and pink color combination.

## ✨ Features

- **Modern Homepage:** Attractive hero section with a fashion banner.
- **Responsive Navigation:** Simple and user-friendly navigation bar.
- **Category Section:** Separate sections for Men's Wear, Women's Wear, and Footwear.
- **Product Collection:** Displays trending fashion products.
- **Product Filtering:** Filter products by category.
- **Search Functionality:** Search products by name or category.
- **Add to Bag:** Add products to the shopping bag.
- **Cart Counter:** Displays the total number of added items.
- **Cart Summary:** Shows selected products and total price.
- **Responsive Design:** Supports desktop, tablet, and mobile screens.
- **Interactive UI:** Smooth scrolling and hover effects.

## 🚀 Getting Started

Follow these steps to run the project on your local computer.

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open Project Folder

```bash
cd Myntra-Unique-Clone
```

### 3. Open in VS Code

```bash
code .
```

### 4. Run the Website

- Open the project in Visual Studio Code.
- Install the Live Server extension.
- Right-click on `index.html`.
- Select **Open with Live Server**.

The website will open in your default browser.
